applied to this repository. All 20 rows below were terminal (`cc:done`) and the file had
been sitting fully complete and unarchived for 33 days, which is exactly the condition
the T2 archive sweep exists to catch — it fired on this file on the first run.

`scripts/progress-snapshot.sh` and `scripts/hook-handlers/wip-guard.sh` all read `Plans.md`
and nothing else. Physical separation is the enforcement: teaching four counters to skip
